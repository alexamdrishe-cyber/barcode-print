# BarcodePrint

Программа для печати штрихкодов (Code128) на термотранспортных этикет-принтерах под Windows.
Работает с любым принтером, установленным в системе: Xprinter, Godex, TSC, Zebra, Argox и др.

## Возможности

- Ввод начального кода: цифры, буквы, смешанные значения
- Автоинкремент хвостовой цифровой части (155678 → 155679 → …; SKU-001 → SKU-002; AB0099 → AB0100)
- Если цифр нет — печать одной и той же этикетки N раз
- Выбор размера этикетки: пресеты (30×20, 40×30, 50×30, 60×40 и др.) + свой размер
- Живой предпросмотр этикетки
- Текст сверху этикетки (кириллица поддерживается)
- Переворот на 180°
- Прямая печать без диалога Windows
- Сохранение настроек между запусками

## Установка

    pip install python-barcode pillow pywin32

## Запуск

    python barcodeprint.py

## Сборка exe

    python -m PyInstaller --onefile --noconsole --name BarcodePrint barcodeprint.py

Готовый файл — `dist/BarcodePrint.exe`.

## Примечания

- Штрихкод — Code128. Латинские буквы и цифры. Кириллица в самом коде не поддерживается (только в поле «Текст сверху»).
- Размер этикетки в драйвере принтера должен совпадать с выбранным в программе.
